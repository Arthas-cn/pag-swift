## 已实现内容

原internal PlaybackController直接提升为public PAGPlayer actor，保留原纯值Timeline、准备、撤销门和限流规则。这样snapshot和同步配置方法仍读写同一actor状态，没有第二个只转发的actor或异步镜像。公开init不创建假提交器；无表面时提交器为nil。原P4注入测试改用这个实际公开类型，已有状态机测试继续执行。

PAGPlayer公开setComposition、replaceComposition、attach/detach、play/pause/stop/rewind、两种seek、repeatCount、scaleMode、render、snapshot/stream。控制和准备仍不进入MainActor，render等待实际GPU完成。新表面预约失败保留旧绑定；成功后才撤销旧工作。预约、绑定和显示代数分别核对，迟到旧清理不能释放新占用。每个绑定只有一份显示消息任务和一份主actor播放意图任务，后台任务弱引用播放器/表面，销毁会结束订阅与预约。

PAGSurface是MainActor的独立CALayer目标，init只检查设备并建立既有显示桥和RenderOwner。设备配置在后台owner完成；实际挂载、布局和拆层在主actor且有租约保护。默认inactive，未布局/挂载不能呈现。配置事务失败或取消时，恢复最后真正发布的配置而非未提交的中间意图；显式拆层即使调用任务已取消也完成清理。显式宿主操作会等待控制actor接受新目标状态，不让调用方紧接render时仍看到旧可用性。

DisplayBinding是可同步撤销的Sendable预约，拥有独立UUID。目标与时间消息使用bufferingNewest(1)，每条包含完整目标状态，tick携带与控制命令同原点的单调微秒。播放器向主actor发送去重的推进意图；暂停/完成后实际暂停系统link。RenderOwner新增waitUntilIdle屏障，在活动提交真正退出后才完成交接，不能把显示租约归还误当作actor已经结束所有完成处理。

DisplayRefreshDriver在主actor管理CADisplayLink：iOS独立表面使用系统默认link，macOS使用NSScreen.main的link。没有可用link时进入不可用/暂停推进状态，不用sleep定时器替代。独立宿主可再次声明active重试；P6将由真实UIKit/AppKit宿主提供跟随窗口/屏幕的工厂。回调只投递小值，销毁时invalidate，不让runloop/target形成永久保活。

平台依据为当前SDK的NSScreen.h::displayLinkWithTarget:selector:及Apple文档：[NSScreen displayLink](https://developer.apple.com/documentation/appkit/nsscreen/displaylink(target:selector:))说明与屏幕同步及视图/窗口工厂的用途；[CADisplayLink](https://developer.apple.com/documentation/quartzcore/cadisplaylink)说明runloop通知、暂停与invalidate职责。两端实现均做了实际Swift编译，不靠旧API记忆填写签名。

## 验证结果

完整库`swift test`报告**357项、57组、无失败**。沙箱中28项GPU测试和1项需显式启用的性能探针跳过；同一debug测试产物以主机权限与Metal API Validation运行8组，**28项全部实际通过**。

本轮新增13项测试：

- 仅用`import pag_swift`验证公开初始化、快照/stream、控制配置、缺合成/缺表面错误和微秒/进度端点，避免@testable掩盖访问级别问题。
- 表面布局取消、最新布局胜出、连续失败回滚到已发布尺寸、预约取消不遗留surfaceInUse、独占占用、换表面失败保留原绑定。
- 播放器释放结束stream并释放预约；旧异步清理不能解除新占用；已取消调用仍实际拆层。
- 真实NSWindow只使用公开PAGSurface/PAGPlayer完成red.pag提交，**不手动调用tick**，系统display link推进并提交有限末帧后发布finished。第449帧/30fps的代表时间为ceil后的14,966,667微秒；首次测试将预期误写为14,966,666，核对既定SceneTiming合同后修正预期，未改生产时间规则。
- 真实窗口隐藏/恢复不覆盖主动pause，2倍scale重提、surface.detach后targetUnavailable、player.detachSurface后missingSurface。
- 在系统GPU完成回调的受控暂停点发起两播放器交接，观察双方注册owner退出屏障后再释放回调，旧render取消，新播放器真实提交成功。故障注入不阻塞主actor或owner执行器。
- 注入无法创建link的工厂，确认自动播放进入suspended，不伪造刷新。

原17项显示桥、覆盖数学、资源/裁剪、整体alpha和drawable回归也全部通过。没有读取最终帧颜色；自动推进和真实GPU完成不能替代屏幕图像对照。

全部**95个库Swift源码**通过iOS26 target、Swift6严格并发、ApproachableConcurrency、warnings-as-errors实际`swiftc -c -whole-module-optimization`编译，目标文件2,678,472字节。iOS系统link目前是编译验证，还没有真机运行。
