## TextSource

`src/codec/tags/text/TextSource.cpp::TextSourceTag/V2/V3` 注册一个 DiscreteProperty。外层存在位后若动画位为真，目前返回 unsupported；静态时由 `src/codec/Attributes.h::AttributeConfig<TextDocumentHandle>` 选择版本读取器。

`src/codec/DataTypes.cpp::TextDocumentBlockCore` 和 `ReadTextDocument/V2/V3` 定义内层字段。先读完整 flags，再字节对齐读值。前六个 BitFlag 直接就是布尔值，不能把 false 解释成“使用 default true”。之后 Value/Custom 位表示是否有载荷。

| 内层次序 | 类型 / 含义 |
| --- | --- |
| 0…5 | applyFill、applyStroke、boxText、fauxBold、fauxItalic、strokeOverFill 六个 BitFlag |
| 6…9 | Float32 baselineShift、firstBaseLine；Float32 二元 boxTextPos、boxTextSize |
| 10…13 | RGB fillColor；Float32 fontSize；RGB strokeColor；Float32 strokeWidth |
| 14…17 | UTF-8 text；UInt8 justification；Float32 leading、tracking |
| V2/V3 增加 | RGB backgroundColor、UInt8 backgroundAlpha |
| V3 再增加 | UInt8 direction |
| 最后一个 Custom | encodedUInt32 字体表 ID |

不另加长度前缀；值均由当前 TextSource tag 子流限定。没有载荷的字段取上述配置默认值，`ReadBlock` 本身不读一个新 tag header。

外层整个属性缺失时使用 `TextDocument` 初始化值：fill=true、strokeOverFill=true、fontSize=24、strokeWidth=1、背景 alpha=0、方向 Default。V2 外层初始化器仅改背景 alpha=255；V3 外层仅改方向 Horizontal。内层 V2/V3 背景 alpha 缺省是 255，V3 方向缺省却是 Vertical。这些差异已有独立片段测试，不能统一为一个所谓默认样式。

原始文本保留全部上述字段；PAGText 只暴露架构合同中的可编辑子集。公开可变数值在 replaceText 前重验。文件非有限值、缺失字体引用和越界枚举失败，不用空文本掩盖读取错误。

## 输入图片的系统边界

`PAGImage.load` 两入口都明确 `@concurrent`。ImageIO 对象与 CGContext 只在后台当前解码调用中使用；返回 Sendable 不可变像素、来源身份与元数据，没有 CGImage/裸指针跨域。

完整解码及 EXIF 转换后保存顶行在前、sRGB 预乘 RGBA8。预先按源尺寸保守计三份 RGBA 缓冲，超限不分配目标像素。方向转换前后尺寸必须吻合，单帧状态必须 complete，取消在前后检查。系统同步解码本身不能强行打断。

真实 PNG/JPEG/WebP、非方形 EXIF=6 照片以及独立 2×2 RGBA PNG 已通过 macOS 主机测试；GIF 单帧由系统编码测试验证。真实多帧 GIF/WebP 在 P2 明确 unsupportedAnimatedImage。此为素材输入 CPU 解码，不涉及读取 PAG 播放的 GPU 输出。iOS 26/macOS 26 最低系统逐平台媒体验证仍随 P6/P8 进行，当前主机通过不能替代它们。
