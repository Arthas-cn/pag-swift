## 测量、反转和提取

`third_party/tgfx/src/core/PathMeasure.cpp`（25–44行）包装 `SkPathMeasure(path,false)`，Trim从不调用nextContour。`SkPathMeasure.cpp` 构造器选择迭代器第一个非空 measure：因此仅使用**首个可测轮廓**；不是第一个Move就停止，也不是全部轮廓总长。反转后这个轮廓可能来自原路径末尾。完整范围直通和零测长分支仍保留其余轮廓。

`tgfx/src/core/Path.cpp::reverse`（588行）调用 PathKit `src/core/SkPath.cpp::reverseAddPath`（977–1030行）。反转轮廓顺序和各条边，闭合轮廓从最后实际存点开始，保留Close；Cubic交换控制点，Quad保持唯一控制点，Conic保持权重。`moveTo`（511行）始终记录，连续/末尾Move与零Line都保留；`injectMoveToIfNeeded`（522行）保证Close后继续Line先回到此前起点新建轮廓。例如：

```text
输入 M(0,0)L(10,0) M(20,0)L(30,0)Z M(99,0)
反转 M(99,0) M(30,0)L(20,0)Z M(10,0)L(0,0)
```

`PathKit/src/core/SkContourMeasure.cpp::getSegment`（565–612行）仅把负start压到0、超长stop压到length，随后要求start<=stop；不做两端对称clamp。长度10时[-5,-1]、[11,12]无输出，[-5,0]、[10,12]都输出Move+零Line，[-5,12]输出整段。`distanceToSegment`（471–518行）的lower-bound使精确顶点先命中前一段，起切会追加零Line。所有成功切片以Move开始、从不追加Close；不能去掉零Line，否则后续cap/dash不同。

方形 `M(0,0)L(10,0)L(10,10)L(0,10)Z` 的独立几何期望：

```text
trim [.75,1.25] => M(0,10)L(0,10)L(0,0) / M(0,0)L(10,0)
trim [.75,.25]  => M(10,10)L(10,10)L(10,0)L(0,0)
```

曲线测长默认resScale=1、层内误差阈值0.5，Float累加和compact点列由 `SkContourMeasure.cpp`（129行起）决定。不是最终显示的1/8像素误差。复用现有Swift StrokeDashMetric测长证据；Trim的Line/Cubic截取须独立保持SkGeometry源Float算序，不能修改已有Stroke的Double截取合同。Quad/Conic可共用已有源Float数学。裁剪后曲线直到最终填充/描边才按显示精度离散。
