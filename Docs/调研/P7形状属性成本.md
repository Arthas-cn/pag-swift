# P7 形状属性动画成本（2026-09-30）

本表是当前主机macOS 27、Swift 6.4 Release的观察，测量新增属性对后台形状准备与共同网格缓存的影响，不是所有PAG文件或真机的帧率保证。运行命令：在`packages/pag-swift`执行`PAG_SHAPE_PROPERTY_BENCHMARK=1 swift test -c release --filter ShapePropertyBenchmarkTests`。1项/1组通过，日志`/tmp/pag-swift-p7-shape-property-cost.log`。

## 口径

语义夹具的轨道覆盖0...64帧，首帧冷准备独立计时，之后32个不同源帧分别测PreparedShapeStore.sample与RenderGeometryCache.mesh。长路径沿矩形边细分，没有故意混入密交叉；该夹具测属性变化和点遍历成本，不能覆盖复杂路径的最坏扫描代价。8192点颜色/alpha动画每次都断言同一ShapeGeometry、同一网格与warm work==1；组位移和矩形变化每次都断言不同几何及网格，不通过返回旧结果取得低耗时。

## 保活与限制

8192点颜色/alpha用例四条形状缓存合计逻辑成本2,629,888字节、网格缓存721,736字节；512点组位移分别177,024与1,514,568字节；矩形分别7,744与61,440字节。颜色/alpha复用不代表源点遍历或保活成本为零；逻辑预算保守累计，不等于allocator实际分配。进程累计峰值RSS从48,087,040到48,906,240字节，包含整个测试进程历史，不能用它证明64MiB逻辑预算就是进程内存上限。

该探针未包含GPU提交、主机合成器或真机热状态；实际drawable正确性、取消与迟到结果另由显示验收测试覆盖。生产根pass继续直接指向显示drawable，颜色/alpha命中不会新增整帧离屏拷贝或像素读回。组整体alpha仍使用既有局部内容附件，不能将局部组混合表述成全屏离屏播放。
