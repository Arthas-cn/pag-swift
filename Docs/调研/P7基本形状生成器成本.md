# P7 基本形状生成器成本

2026-09-30，当前主机macOS27.0（26A428）、Swift6.4，独立Release测试进程。命令：

```sh
PAG_SHAPE_GENERATOR_BENCHMARK=1 swift test -c release --filter ShapeGeneratorBenchmarkTests
```

3项/1组通过，日志`/tmp/pag-swift-p7-generators-cost.log`。这是单次主机CPU观测，不代表所有资源、GPU时间、真机帧率或最低系统性能；不将测试执行时间和编译耗时混入单帧成本。

## 方法

真实PreparedShapeStore和RenderGeometryCache，默认64MiB逻辑预算、16,777,216工作上限。首帧prepare和cold mesh单独计时；源轨道范围0...64，随后1...32帧逐帧计prepare及mesh。颜色场景断言几何/网格同一对象、warm work=1；几何动画断言两者身份变化，不能用不变尾帧充当动画成本。

| 场景 | 首次prepare ms | cold mesh ms / work | 后续prepare中位 ms | mesh中位 / P95 / 最大 ms |
| --- | --- | --- | --- | --- |
| 固定Ellipse改颜色 | 0.103458 | 0.254458 / 10831 | 0.000875 | 0.000083 / 0.000084 / 0.000291 |
| 2048顶点Polygon改颜色 | 0.003500 | 0.794833 / 278537 | 0.000875 | 0.000083 / 0.000084 / 0.000292 |
| Ellipse尺寸动画 | 0.003833 | 0.102875 / 10831 | 0.001334 | 0.092917 / 0.107250 / 0.118083 |
| 五角Star内外半径及圆度动画 | 0.002917 | 0.035292 / 4380 | 0.001375 | 0.041334 / 0.073416 / 0.073417 |
| Ellipse描边dash相位动画 | 0.024459 | 0.278666 / 31445 | 0.001625 | 0.162875 / 0.200750 / 0.359500 |

颜色两场景各有相同的7360逻辑字节源帧缓存；网格缓存分别16640与393152逻辑字节，说明颜色帧的准备成本不随PolyStar展开点数增长。变化场景源帧缓存7744/7744/8384，网格缓存488448/796032/1503552。这里的结论只针对本次输入和完整描述匹配；改变点数、几何参数、矩阵或描边样式必须重新生成。

进程累计峰值RSS从47,595,520到50,413,568字节；不能把这些数当成单个输入的净分配，也不保证整个进程被64MiB逻辑预算硬限制。没有测离屏图片、像素导出或CPU回读成本。

## 限制与取消

Star的一百万points在源Int32范围内，但两百万段的预付数组成本超过默认字节预算，明确报`maximumRenderGeometryBytes`，未发布路径前缀或网格；观测0.249542ms、work34、缓存条目0。没有降低精度或删掉顶点来换取成功。

2048点Star的后台请求准备就绪后5ms发出取消，实际在work2,043,416时取消，请求到完成0.024ms，缓存条目0。任务句柄始终取消并等待；不保证取消在固定几何阶段发生，也不把一次快速响应当成所有输入的固定上界。
