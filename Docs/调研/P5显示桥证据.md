# P5 显示桥与后台 Metal 所有权证据

2026-09-28。P4已验收，本记录用于P5最先要求的桥接编译/生命周期证明；**不是P5整阶段验收，也不是画面验收**。

## Apple 依据

- [Creating a custom Metal view](https://developer.apple.com/documentation/metal/creating-a-custom-metal-view)：官方示例提供主线程/后台绘制配置，UIKit/AppKit共用渲染委托。
- [CAMetalLayer](https://developer.apple.com/documentation/quartzcore/cametallayer)：drawable.texture直接作为颜色附件，command buffer负责present，及时释放drawable避免池耗尽。当前SDK头文件说明nextDrawable可能等待约一秒并返回nil，framebufferOnly推荐true，maximumDrawableCount只接受2或3。
- 官方压缩包 [CreatingACustomMetalView.zip](https://docs-assets.developer.apple.com/published/94ef84014d42/CreatingACustomMetalView.zip)，108618字节，SHA-256 `38fda178f3ebde9da725a30de5e63cb46af8d36e372375f260ceec382bfe117f`。仅解压到 `/private/tmp/pag-swift-apple-metal-sample`，不加入编译依赖。
- 包内 `Application/AAPLView.m:123–138` 与 `:151–156`：后台配置用同一 `@synchronized(_metalLayer)` 包住resize和render。可证实需要串行化尺寸依赖；本库不照搬会让主线程等待完整render的锁，改用异步租约排空。UI结构变化与后台层访问不会并发。
- 本机SDK `usr/lib/swift/Dispatch.swiftmodule/arm64e-apple-macos.swiftinterface` 声明DispatchSerialQueue的SerialExecutor与隔离检查；最低系统26允许直接使用，不需要旧架构回退。

这些是平台线程/显示证据，不用于发明PAG字节布局。租约、事务和预算是本库实现选择，不能称为上游格式限制。

## 严格并发探针

临时源 `/private/tmp/pag-swift-p5-bridge-probe.swift` 编译了：私有CAMetalLayer的受控bridge、`sending any MTLDevice`转移、DispatchSerialQueue自定义actor executor、owner内配置与命令队列、drawable作用域、command buffer完成回调向continuation发送标量。

macOS26与iOS26均使用Swift6、strict-concurrency=complete、warnings-as-errors、ApproachableConcurrency，并实际 `swiftc -c`：两者exit=0。没有preconcurrency导入或nonisolated(unsafe)。仅裸层桥局部unchecked Sendable；生产版本仍必须以租约和生命周期测试证明其同步约束。

沙箱内设备查询返回nil；同一已编译探针在主机权限下运行得到 `device=Apple M5 mainThread=false queue=true`、挂载普通CALayer成功。探针没有打开窗口，没有申请drawable或读回像素，因此只能证明设备存在、所有权转移、后台executor与层挂载，不能称为真正渲染通过。

## 已落地的桥接与验证

`DisplayGeometry` 校验向上取整像素、有限正倍率、单边/面积预算及宽整数溢出边界。`DisplayTargetMailbox` 使用checked Sendable与Mutex保存纯值，配置/主层树变更/绘制三类租约共用唯一访问槽。beginMutation只撤销身份并阻止新访问，不提前释放旧资源；异步等待、取代等待、错误归还、重复归还与不可逆close都有确定性测试。

`DisplayTargetBox` 局部unchecked Sendable经过以下边界约束，不能推广为CAMetalLayer自身可跨域自由使用：

| 平台访问 | 唯一允许域与保护 |
| --- | --- |
| CAMetalLayer初建 | MainActor，尚未发布box，不接受外部CAMetalLayer |
| mount/frame/contentsScale/unmount | MainActor且持有当前事务的mainMutation租约；无租约就不触碰层 |
| device/格式/drawableSize/nextDrawable | isolated RenderOwner且持有对应配置/绘制租约；可阻塞调用不持值锁 |
| drawable借用 | 仅同步owner作用域，调用前后检查取消/epoch；没有裸drawable返回值，autoreleasepool及时放开引用 |
| shutdown | close阻止新访问，异步等剩余租约归还，再由MainActor移除层；任务取消不能提前拆层 |

`RenderOwner` 以DispatchSerialQueue作为真实actor executor，持有发送转移后的device并在后台创建命令队列；配置完成前后检查取消与事务。当前没有PlaybackSubmitting的假实现，也未生成空白帧冒充PAG结果。公开PAGSurface/PAGPlayer与实际in-flight GPU资源表尚待接入，届时必须把显示epoch、播放提交gate和绘制租约贯通，不能只凭本轮租约测试宣称旧GPU提交已经被完整阻止。
