# P7 图层混合模式真实字段与绘制次序（2026-10-21）

只读上游`src/codec/tags/LayerAttributes.cpp::MakeFromLayerAttributesTag`表明LayerAttributes三个版本的`blendMode`是缺省`Normal`的单字节Value；`include/pag/types.h::BlendMode`定义`Normal=0`、`Screen=2`、`HardLight=8`。`src/base/utils/TGFXCast.cpp::ToTGFX`将两者分别映为TGFX `Screen`、`HardLight`，不能把非零值仅消费后按SrcOver绘制。现有`PAGBlendModeEvidenceTests`以三份原始资源读取：`nodegroup_clip1.pag`的合成31、预合成层263/265为2，`nodegroup_clip2.pag`的合成31、预合成层265为2，`tougao.pag`的合成2、Shape层389为8；日志`/private/tmp/pag-blend-evidence-current.log`。

`src/rendering/renderers/LayerRenderer.cpp::DrawLayer`在图层transform与内容之外调用`Recorder::saveLayer(alpha, ToTGFX(layer->blendMode))`；因此模式必须作用于**该层完整内容与此前背景**，不能在预合成的每个子draw上各自Screen。`src/rendering/graphics/Modifier.cpp::BlendModifier`在最终Graphic绘制时设置模式，嵌套两个非Normal模式不能直接合并。TGFX `third_party/tgfx/src/gpu/BlendFormula.cpp`的Screen系数为源`One`、目标`OneMinusSrc`，在预乘颜色上可由Metal固定混合器表达；HardLight属于`mode>Screen`的独立非系数着色路径，不得以Screen或SrcOver代替。

当前库`PAGLayerDecoder.readLayerAttributes`对非默认模式保留`layerBlendMode`门禁，以上三份完整文件仍明确unsupported。后续Screen应只对完整预合成结果借内容紧边界的局部附件，最终根drawable用Screen系数合成；局部子内容仍按SrcOver，不能让其各自与背景Screen。HardLight需独立证明显示目标颜色读取与数学等价或其它有界组合路线；未完成前保持门禁。整个过程不新增固定整帧中转或CPU读回。

首次Screen接线后资源审计显示两份预合成又停在`layerTag:57`。只读上游`src/codec/tags/effects/LevelsIndividualEffect.cpp::LevelsIndividualEffectTag`证明按RGB、Red、Green、Blue顺序各五条SimpleProperty，加通用opacity与mask列表。`src/rendering/filters/LevelsIndividualFilter.cpp::Apply/FRAGMENT_SHADER`先分别处理RGB通道，再应用共同RGB级别；alpha不改。原始载荷独立测试`PAGLevelsIndividualEvidenceTests`发现`nodegroup_clip1`的层263/265及`nodegroup_clip2`的层265均静态、opacity255、无自定义mask，Red与Blue的outputWhite=0且其它各项缺省，Green及共同RGB五项缺省。因此这些记录的颜色效果严格是R/B归零、G不变；不能把tag57当完全无效果忽略。日志`/private/tmp/pag-levels-evidence1.log`。

Levels窄范围接线后，两份完整文件下一门禁是预合成层tag56。`PAGMotionTileEvidenceTests`按上游十字段读得这两份主目标层263/265均静态中心(360,640)、tile100%×100%、输出300%×300%、镜像true、phase0、opacity255、无自定义mask；`nodegroup_clip1`另有层115动态tile62%→其它取值且与Bulge同层，需独立处理。源标签顺序在主目标层是**57→56**。上游`MotionTileFilter::Apply/filterBounds`按输入内容范围归一中心并扩输出，片元在输出单位域反求平铺来源；实际绿通道裁剪是线性逐像素操作，与该空间采样对已预乘输入可交换，但边界的双线性透明采样仍须在完整坐标域验证。日志`/private/tmp/pag-screen-motiontile-evidence.log`及`/private/tmp/pag-screen-effect-order.log`。
