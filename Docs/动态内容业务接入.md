## 源槽与内容合同（已实现）

上游 `src/base/File.cpp::updateEditables` 按编码 DFS 给文本源去重、按 image resource ID 给图片分组；`src/rendering/layers/PAGFile.cpp::replaceText/replaceImage` 对关联实例应用替换。本库沿用 `EditableCatalog`，不增加 PAG 字段。

- `PAGFile.contentSlots` 与 `PAGComposition.contentSlots` 返回 `[PAGContentSlot]`，只含文件允许编辑的真实源槽。稳定顺序为文字索引升序，再图片索引升序。
- `PAGContentSlot` 为不可变 `Sendable/Hashable` 值：`tag`、`kind`（text/image）、`sourceIndex`、`sourceNames`、`size`、`instanceCount`。`size` 为源层局部坐标中的文本框或图片资源逻辑尺寸；点文字没有文本框时为 nil，绝不是实例屏幕尺寸。
- 一个槽所有非空源名一致且该名没有归属于其它源槽/非编辑层时，使用该名称。多名、无名、重名、跨类型同名使用 `text:<index>` / `image:<index>`。派生名碰到任何真实名称或已分配 tag 时，依次追加 `#1`、`#2`，直到唯一。调用方查询，不负责拼接。
- 同一源槽不论有多少嵌套实例只请求一次 provider。共享图片资源的不同名称不能拆成多个业务槽；原有索引/名称编辑仍保留。
- `DynamicContent` 增加 `.unchanged`（不改当前覆盖）和 `.original`（删除该源槽的内容、可见性、占位及文字布局覆盖，恢复文件原始内容）。`.hidden` 只隐藏该槽；`.image` 保留 PAGImage 的动态属性。
- `PAGComposition.apply` 只根据目录匹配，不把错误 tag 静默作用到同名其它类型。不改图层时间、变换、alpha、mask、clip 或堆叠；其它图层保持原样。

## 异步业务入口（已实现）

本轮新增声明：

```swift
public typealias PAGContentProvider = @Sendable (PAGContentSlot) async throws -> DynamicContent
public struct PAGContentOptions: Sendable {
    public init(timeout: Duration = .seconds(5), maximumConcurrentRequests: Int = 4,
                maximumPendingRequests: Int = 128) throws
    public static var standard: PAGContentOptions { get }
}
extension PAGPlayer {
    public var contentSlots: [PAGContentSlot] { get }
    public var contentEvents: [PAGContentEvent] { get }
    public func contentUpdates() -> AsyncStream<PAGContentEvent>
    public func setContentProvider(_ provider: @escaping PAGContentProvider,
        options: PAGContentOptions = .standard,
        loadImageFromURL: (@Sendable (URL) async throws -> PAGImage)? = nil) throws
    public func updateContent(_ content: DynamicContent, forTag tag: String) throws
    public func resolveContent(forTag tag: String,
        placeholder: DynamicContent = .unchanged,
        using provider: @escaping PAGContentProvider) throws
    public func cancelContentRequests()
}
```

上述控制位于 PAGPlayer actor；不等待 provider 返回。`setContentProvider` 对当前合成全部源槽各请求一次，未装合成抛 `missingComposition`；超过待处理预算在调度前抛资源错误。`updateContent` 是按 tag 提交类型化内容，`.original` 恢复源内容。`resolveContent` 可指定立即排队应用的占位，失败/超时保留已应用占位；默认 `.unchanged` 保留之前内容。非法 tag、类型、缺 URL 回调在入队前拒绝。其它 provider/布局准备失败写事件，播放器继续。单槽事件包含文档摘要、会话、请求版本、tag、状态及耗时；最多留最近 256 条，不每帧写磁盘。

播放器接受 `@Sendable (PAGContentSlot) async throws -> DynamicContent`，默认保留原内容，逐源槽解析；支持更新单个 tag、取消整个会话。provider 不在每帧调用，不负责帧调度或网络框架类型。

会话身份、文档身份和每 tag 请求版本一起校验。超时/取消先结束等待，再取消工作；不使用会等待非合作子任务退出的 task group 竞争。未退出的宿主工作继续占用有限并发配额，避免反复超时产生无界后台任务。单槽失败保留约定回退并发出可观察结果，不使 PAG 播放失败。同步调用错误抛错；异步 provider/准备失败、超时、取消和迟到结果单独记录。

## 动图和时钟（宿主适配及库接入已实现）

新增声明：`PAGImageFrame(width:height:pixels:)` 为完整画布、顶行在前、紧密行、sRGB 预乘 RGBA8 的不可变值；尺寸及字节数验证且单帧最多 64 MiB。`PAGAnimatedImageInfo(size:frameDurations:playCount:)` 验证至多 8192 帧、每帧正微秒、总时长不溢出，playCount=nil 无限循环，正整数为总播放轮数。

`PAGAnimatedImageSource: Sendable` 提供不可变 `info` 与同步 `frame(at:) throws -> PAGImageFrame?`。调用仅在后台媒体 owner，不能做网络、等待主线程或启动 Timer；宿主负责 decoder 串行化和完整画布合成。nil 表示暂未就绪，库保留同一素材最近帧或首帧，不闪回其它素材。`PAGImage.animated(from:) async throws` 只读取首帧和时间表，单帧归一为 still；`PAGImage.make(from:) async throws` 接入宿主静态帧。实时路径最多保留 32 张帧、16 种素材，按 LRU 淘汰；精确等待内部入口仍按每素材最近帧留存；解码前将已有留存与新素材的三份画布保守峰值一起纳入 64 MiB owner 预算；宿主 decoder 自身预算另计，不能称作库帧缓存。

宿主独立提供完整合成帧、帧时长和循环元数据；库不暴露/依赖 SDWebImage。Demo 使用 SDWebImage 与实际需要的 WebP coder，适配器负责系统图片到不可变帧的转换和隔离。帧资源按预算按需读取，不预解全动画。

2026-10-23 用户补充合同取代旧动图时序（已实现，定向回归通过）：GIF/WebP 使用独立累计播放进度，只随 PAG 的播放/暂停及整个宿主挂起而推进/冻结；根循环、seek、rewind 不重置它。2 秒 PAG 循环后，4 秒动图继续从约 50% 播放。新素材安装从零起计，同素材及其它 tag 的编辑保留进度；换文档重置，有限动图循环播满保持末帧。图层是否绘制仍服从 PAG，但单层暂时不可见不回拨或暂停该素材时钟。外部视频仍保留原图层内容时间合同。跑马灯沿用累计激活时间：有效呈现后开始、暂停/不可见冻结、根循环不重置；seek 保留、rewind 重置，文字/配置/文档变化只重置对应状态。不能增加独立 Timer。

时钟修正（已实现）：每个实例持有独立同步激活状态；同文档准备新快照时，仅对文字与布局均未变化的实例共享该状态，旧请求仍受提交许可约束。每个有效完成帧报告完整可见实例集合，缺席实例停止累计；恢复后接着累计。新 `setComposition` 与 rewind 清零，单 tag 内容更新不清零其它文字。生产激活边界已改为有效系统 presented 回调；GPU 完成只发布局部纹理。正式 Demo 画面仍须另行验收。

## 2026-10-23 独立动图时序修正

原实现使用 PAG 图层内容时间，根循环会使动图回到对应首帧，确实不符合用户要求。现在 `PlaybackTimeline.imageElapsed` 累计实际播放时间，`ImageAnimationTimeline` 按素材实例记录安装起点；循环、seek、rewind 不重置它，没有新增 Timer。`IndependentImageTimingTests` 六项覆盖真实播放器请求、2 秒 PAG / 4 秒动图的 50% 边界、暂停恢复、挂起、命令发生在 tick 之间、有限循环和不同 tag 的安装起点。

2026-10-23 调度方案核对：VAP 的 `AnimatedDynamicPlayback.prepare` 为每个动图创建 `SDAnimatedImagePlayer`，并把帧回调交给 Metal 纹理更新；其 runtime 桥接将循环数设为零。SDWebImage 5.21.7 的 `displayDidRefresh` 使用每帧 duration，预取下一帧，buffer miss 时等待，不跳帧。当前 PAG 方案同样使用 SD 的逐帧 duration（可以不等长），但由屏幕刷新驱动独立累计时间，并按该时间定位有效帧；PAG 根帧率不决定 GIF/WebP 帧率。保留此方案可满足根循环不重置和按实际播放时间推进的要求；直接接入 SD 播放器会增加独立刷新及缓冲所有者，且其缺帧等待策略会延长动画。此前同步按需读取会使慢解码延迟帧准备；现已补齐有界异步预取，生产显示使用非等待采样，具体边界与测量见下文。

### 有界异步预取（已实现）

动图有界预取补强（已实现，不改变公开素材协议）：实时显示使用非等待采样，解码由独立串行 worker 执行。每 owner 最多一项实际解码、16 项合并后的待请求、32 张缓存帧及 16 种素材；缓存加在途三份画布预留共用 64 MiB 预算。每槽只请求当前缺失帧或紧邻下一帧，不自动遍历整个动画。暂缺帧保持本槽最近已选帧（已淘汰则首帧），预取结果不能提前显示；暂停不启动新解码，已有同步调用最多完成当前一项。新帧计划移除不再安装的素材，迟到旧素材不能回填；owner 释放取消唯一任务，worker 不保活播放器。已有精确帧计划/像素探针保留等待指定帧的内部入口，生产显示显式使用非等待路径。所有选择继续依赖独立素材时间，不新增计时器。

### 槽位遮罩公开合同（已实现，窗口验收进行中）

在 `PAGImageContentOptions` 增加 `scaleMode: PAGScaleMode? = nil` 与 `mask: PAGImageMask? = nil`；前者为空保留文件图像适配规则，业务头像可明确选择 `.aspectFill`。遮罩只作用于这次内容替换，恢复原内容或后续无遮罩替换会清除它。同一素材在其它槽位不受影响。

`PAGImageMask: Sendable` 支持 `.alphaImage(PAGImage, scaleMode: PAGScaleMode = .aspectFit)`、`.originalImage(tag: String, scaleMode: PAGScaleMode = .aspectFit)`、`.circle`、`.ellipse`、`.roundedRectangle(cornerRadius: Double)` 和 `.path(PAGMaskPath, scaleMode: PAGScaleMode = .aspectFit)`。PNG 只使用 alpha，颜色不参与覆盖；原槽图像读取不可变文件资源，并还原裁边 anchor/scale，不读取该槽当前替换内容，也不隐藏或修改来源槽。圆形内切目标逻辑框，椭圆填满逻辑框；圆角半径为短边比例 `0...0.5`。

`PAGMaskPath.init(_ path: CGPath, coordinateSize: PAGSize, usesEvenOddFillRule: Bool = false) throws` 将 Core Graphics 路径复制成不可变命令；坐标左上原点、y 向下，允许曲线和多轮廓，最多 4096 个元素，所有坐标有限。默认非零填充，可选择奇偶孔洞。形状/路径在后台安装内容时栅格化一次，最长边最多 2048 像素，之后按静态 alpha 纹理缓存；每帧只在同一 Metal 图像 draw 中乘 alpha，不逐帧裁剪头像、不新增根离屏复制。该分辨率是当前明确的路径边缘质量上限。

动画头像每帧共用同一遮罩；静态首帧选择可以与遮罩组合。动态或视频素材不能作为遮罩；视频头像暂不接受此选项。非法源 tag、类型、路径或半径在内容准备时抛调用错误，异步 provider 路径记录失败并保留旧内容。准备过程支持取消，原有版本门闩阻止迟到提交。所有新增类型为值或不可变 `Sendable` 快照，不持有 UI 对象或额外时钟。

## 最小业务接入

业务先用 `file.contentSlots` 查询素材实际提供的 tag，再把产品约定的文字槽、静图槽、动图槽名称传给下面函数。三个 tag 是查询结果中的业务名称，不能把图片文件名、图层序号或屏幕位置猜成 tag；实际素材没有某类槽位时，不应制造该类配置。一个 tag 对应源槽全部实例。

以下函数可放到 Demo 宿主 target 中直接使用；`DemoSDWebImage` 来自同 target 的 `DemoSDWebImageSource.swift`。复用到其它宿主时，将这个适配文件与它的宿主依赖一起接入。公开库 API 始终没有 SDWebImage 类型。

```swift
import Foundation
import pag_swift

/// 以已查询的三个业务 tag 配置内容；宿主加载 GIF/WebP，库完成请求、选帧和呈现。
func configureExample(_ player: PAGPlayer, pagURL: URL,
                      titleTag: String, stillTag: String, animatedTag: String,
                      stillURL: URL, animatedURL: URL) async throws {
    let file = try await PAGLoader.shared.load(from: pagURL)
    let slots = Dictionary(uniqueKeysWithValues: file.contentSlots.map { ($0.tag, $0) })
    guard Set([titleTag, stillTag, animatedTag]).count == 3,
          slots[titleTag]?.kind == .text,
          slots[stillTag]?.kind == .image,
          slots[animatedTag]?.kind == .image else {
        throw PAGError.invalidArgument("exampleSlotConfiguration")
    }
    try await player.setComposition(file.composition)
    try await player.setContentProvider { slot in
        switch slot.tag {
        case titleTag:
            return .text("这是一段可能超出原文本框的业务标题",
                         layout: .marquee(try PAGMarqueeOptions(speed: 45, gap: 24)))
        case stillTag:
            return .image(try await PAGImage.load(from: stillURL))
        case animatedTag:
            return .image(try await DemoSDWebImage.load(from: animatedURL))
        default:
            return .unchanged
        }
    }
    try await player.play()
}
```

界面使用 `PAGView(player: player)`；UIKit/AppKit 使用同库原生宿主（Demo 的 `NativeDemoView` 示范接入）。每个显示位置保有自己的 player；多个 player 可以共享 `PAGLoader` 的不可变文档。provider 只在设置或显式重取时调用，不在逐帧路径请求宿主。

后续更新不需要重装文件或遍历图层：

```swift
// 这些 tag 与 configureExample 相同，来自当前文件槽位目录。
try await player.updateContent(.text("短标题", layout: .truncate), forTag: titleTag)
try await player.updateContent(.hidden, forTag: animatedTag)
try await player.updateContent(.original, forTag: animatedTag)
try await player.resolveContent(forTag: animatedTag, placeholder: .unchanged) { _ in
    .image(try await DemoSDWebImage.load(from: anotherAnimatedURL))
}
// 页面结束：先撤销宿主供给，再停止显示并释放合成。
await player.cancelContentRequests()
await player.pause()
try await player.setComposition(nil)
await player.detachSurface()
```

`updateContent` 返回表示接受更新，不等于素材已显示；用 `contentUpdates()` 观察 `.applied`/`.failed`/`.timedOut`/`.cancelled`/`.discarded`，再用播放诊断区分提交、GPU 和呈现。`.unchanged` 保留当前覆盖，`.original` 才删除覆盖并恢复文件内容。原文件内容为空时仍为空，不影响整段播放。点文字、竖排或不支持的路径/多行跑马灯组合会报告 `unsupportedFeature`，不会偷偷按普通横排显示。

## 宿主 SDWebImage 配置

适配位置：`app/pag-swift-demo/pag-swift-demo/DemoSDWebImageSource.swift`；Demo 工程链接 SDWebImage 5.21.7、SDWebImageWebPCoder 0.15.0，后者使用 libwebp 1.6.0（以工程 `Package.resolved` 为准）。库根 `Package.swift` 没有这些依赖。

Demo 示例从本地 bundle 读取最多 64 MiB 的素材；实际产品可在宿主网络层和 SDWebImage 缓存层取得数据后构建相同适配器。`SDImageWebPCoder` 注册一次；`SDAnimatedImage` 与 coder 的访问由 `Mutex` 串行化，不跨 actor 传递 `UIImage`/`NSImage`，不调用 `preloadAllFrames`。SD 返回完整合成帧，宿主统一转为预乘 sRGB RGBA8；库按帧时长和总轮数调度，不另设 Timer。SD coder 对极短帧时长的归一化属于宿主解码语义，库使用适配器传入的实际时间表。
